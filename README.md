## Practical Assignment

### Employee Management CLI

A command-line Employee Management application was developed using Python.

The application allows users to manage employee records through different operations.

## Features

- Add Employee
- Update Employee
- Delete Employee
- Search Employee
- List Employees
- Find Employee with Highest Salary
- Calculate Average Salary
- Filter Employees by Department
- Exit

## Employee Details

Each employee record contains:

- Employee ID
- Employee Name
- Salary
- Department

Employee records are stored using Python dictionaries inside a list.

## How to Run

1. Open the day-01 folder in VS Code.

2. Open the terminal in VS Code.

3. Check that Python is installed:

python --version

4. Navigate to the exercises folder:

cd exercises

5. Run any programming exercise:

python exercise01_reverse_string.py

Example:

Enter a string: hello
Reversed string: olleh

6. To run the Employee Management CLI, go back to the day-01 folder:

cd ..

7. Navigate to the employee-management folder:

cd employee-management

8. Run the application:

python employee_management.py

9. The Employee Management System menu will be displayed in the terminal.

Example:

================================
   Employee Management System
================================
1. Add Employee
2. Update Employee
3. Delete Employee
4. Search Employee
5. List Employees
6. Highest Salary
7. Average Salary
8. Department Filter
9. Exit
