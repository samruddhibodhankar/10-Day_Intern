## Practical Assignment - Student Management System

The `management-system` folder contains a Python-based student management system.

### Features

- Add student
- Update student
- Delete student
- Search student
- Filter students
- Sort students
- Display all students
- Calculate statistics
- Course-wise statistics
- JSON data storage
- Exception handling for invalid input

### Data Stored

Student records contain:

- ID
- Name
- Age
- City
- Course
- Marks

Student data is stored in:

`students.json`
